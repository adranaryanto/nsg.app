# NSG App

Web application untuk pengelolaan **logbook, stok barang, anggota, dan peminjaman**.

## Fitur

* 📋 Logbook
* 📦 Manajemen stok barang
* 👥 Daftar anggota
* 📅 Kalender peminjaman
* 🔄 Pengelolaan peminjaman barang
* 🗑️ Tambah, edit, dan hapus data

## Struktur Project

```text
nsg.app/
├── static/
├── templates/
├── app.py
├── README.md
└── ...
```

## Menjalankan Project

Masuk ke folder project:

```powershell
cd "D:\data\logbook_web"
```

Kemudian jalankan aplikasi sesuai konfigurasi project.
